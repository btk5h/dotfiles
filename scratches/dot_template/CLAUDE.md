# Scratch Folder

This is a throwaway workspace created by `mkscratch`. It is not a project, has no
build system, and nothing here is version controlled. Prototype freely — create
whatever files, scripts, and data are convenient, and don't worry about structure
or cleanup.

## Persisting Context

Everything outside of files in this folder is lost between sessions, so write down
anything worth keeping:

- Update this file with the goal of the scratch, the current state of the work, and
  any decisions or dead ends already explored.
- Split longer notes into their own markdown files (e.g. `findings.md`,
  `api-notes.md`) and link them from here.
- Record commands, URLs, and snippets that took effort to figure out.
